# Blush Nail Room website

The website for Blush Nail Room, inside Amour Hair Co., 7 Broadwater Street East, Worthing.
Built with Astro and hosted on Vercel at https://blushnailroom.co.uk

## Where things live
- `src/pages/index.astro`: the homepage content
- `src/layouts/Base.astro`: the header, footer and page settings shared by every page
- `src/styles/global.css`: colours, fonts and layout
- `src/data-schema.json`: business details for Google (address, hours, prices, FAQ)
- `public/images/`: photos (only use client photos with consent, hands only, no filters)

## Changing something
Ask Claude in the BLUSH project, then upload the changed file to GitHub.
Vercel publishes the change automatically within a minute or two.
